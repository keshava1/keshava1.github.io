# keshava1.github.io

Portfolio site using the original System.css layout.

Serve locally with `python3 -m http.server 8000`, then open
`http://localhost:8000`. No build step is required.

- `index.html`: introduction, experience and project lists, skills, and contact.
- `info.js`: shared experience and project data.
- `experience/`: contribution details for each role.
- `components/`: the original dropdown navigation and shared experience headers.
- `style.css`: small spacing and mobile adjustments to System.css.
- `Keshav_Acharya.pdf`: the latest supplied resume.
- `images/SOURCES.md`: sources for company images.

The original System.css stylesheet loads from its existing online source.
